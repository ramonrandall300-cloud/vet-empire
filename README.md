# Vetigo

Create a multi-tenant SaaS veterinary clinic management system. While providing each clinic with its own independent panel and data management, it allows me to manage an unlimited number of veterinary clinics from a single platform. Create a complete clinic management ecosystem with a subscription-based revenue model. Build out each of the sidebar navigation menu item's pages.
